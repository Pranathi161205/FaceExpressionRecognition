﻿#  Facial Expression Recognition (FER)

A Deep Learning based Facial Expression Recognition system that detects human emotions from facial images in real-time.

##  Overview

This project uses Convolutional Neural Networks (CNN) to classify facial expressions into different emotion categories such as:

- 😄 Happy
- 😢 Sad
- 😠 Angry
- 😲 Surprise
- 😐 Neutral
- 😨 Fear
- 🤢 Disgust

The model is trained on a facial expression dataset and can predict emotions from live webcam feed or images.

---

##  Features

- Real-time emotion detection
- Deep Learning based CNN model
- Image preprocessing & face detection
- Easy-to-use interface
- High accuracy emotion classification

##  Installation

1️⃣ Clone the repository

git clone https://github.com/Pranathi161205/FacialExpressionRecognition-FER-.git


2️⃣ Navigate to project folder


cd FacialExpressionRecognition-FER-


3️⃣ Create virtual environment


python -m venv fer_env


4️⃣ Install dependencies


pip install -r requirements.txt
